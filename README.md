# 🏛️ Gotera Church Digital Management System

A modern, feature-based digital management system for **Gotera 44tu Felege Yordanos St. Selassie & St. Arsema Church**.

## 📋 Features

| Feature | Description |
|---------|-------------|
| 👥 Member Management | CRUD, search, duplicate prevention |
| 💰 Contribution Tracking | Monthly contributions with payment methods |
| 📊 Participation Tracking | Event attendance and church activities |
| 🏆 Builder History | 10-month qualification and museum records |
| 📅 Event Management | Create and publish events |
| 📢 Announcements | Church announcements |
| 📞 Appointment Requests | Public requests for administrator meetings |
| 📈 Reports & Dashboards | Real-time statistics and exports |
| 🌍 Multilingual | English and Amharic support |

## 🛠️ Technology Stack

| Layer | Technology |
|-------|------------|
| Backend | Laravel 11+ (PHP 8.4) |
| Frontend | React + TypeScript + Vite |
| Database | MySQL 8.0 |
| Styling | Tailwind CSS |
| Package Manager | Composer (backend), pnpm (frontend) |
| Version Control | Git + GitHub |
| CI/CD | GitHub Actions |

## 🚀 Quick Start

### Prerequisites
- PHP 8.4+
- Composer
- Node.js 20+
- pnpm
- MySQL 8.0
